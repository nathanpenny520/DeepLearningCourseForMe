# 01 · Random Variables & Distributions

随机变量与分布：PMF/PDF/CDF 三件套、常见离散分布（伯努利/二项/泊松）、连续分布（均匀/指数/正态）、CDF 与 PDF 互逆的数值验证。

## 前置要求

- 已按 [`../guide.md`](../guide.md) 配置好虚拟环境
- 建议先完成 calculus 07（积分与概率衔接）

# 03 · Eigenvalues & Eigenvectors

特征值与特征向量：从定义到特征分解，从对称矩阵正交对角化到 PCA 入门，全程配 2D 可视化建立几何直觉。代码为主，每个概念配多个可运行实例。

## 前置要求

- Python 3.12
- 已按 [`../guide.md`](../guide.md) 配置好虚拟环境并安装依赖
- 已完成 [01 Tensor Basics](../01-tensor-basics) 和 [02 Matrix Operations](../02-matrix-operations)
- 关键前置：矩阵乘法、行列式、逆矩阵、对称矩阵、2D 线性变换

## 课程内容

| 章节 | 内容 |
|------|------|
| 0 | 环境配置与导入 |
| 1 | 特征值与特征向量的定义（几何直觉 + 2D 可视化） |
| 2 | 特征方程与特征多项式（2×2 手算 + 代码验证） |
| 3 | PyTorch 求解（linalg.eig / eigvals，复数特征值，验证 Av=λv） |
| 4 | 特征值的基本性质（迹=特征值之和，det=特征值之积，可逆性） |
| 5 | 特征分解与对角化（A=VΛV⁻¹，矩阵幂快速计算） |
| 6 | 对称矩阵的正交对角化（实特征值，eigh，eig vs eigh 对比） |
| 7 | 几何直觉深度可视化（特征向量=不变方向，旋转矩阵的复特征值） |
| 8 | 应用入门（斐波那契数列 + PCA 主成分分析） |
| - | 课后练习（基础 / 验证 / 几何 / 综合 / autograd 衔接） |

## 学习建议

- 第 1 节和第 7 节的可视化是整节课的核心，务必跑一遍
- 重点理解：特征向量是线性变换中"方向不变"的向量
- 对称矩阵的正交对角化是 PCA 的数学基础，第 6、8 节要连起来看
- 遇到环境问题先查 [`../guide.md`](../guide.md)

# 01 · Derivatives

微积分模块开篇：从极限定义（第一性原理）出发理解导数，逐步推导常用函数导数与全部求导法则（含链式法则证明），掌握数值微分及其误差分析，用 PyTorch autograd 交叉验证，最后落到梯度下降——理解"为什么负梯度方向就是学习方向"。

## 前置要求

- Python 3.12
- 已按 [`../guide.md`](../guide.md) 配置好虚拟环境并安装依赖
- 建议先完成 [linear-algebra](../01-linear-algebra) 模块（会用张量与 autograd 基础）

## 课程内容

| 章节 | 内容 |
|------|------|
| 1 | 导数定义：平均变化率 → 瞬时变化率（极限） |
| 2 | 常见函数导数与推导 |
| 3 | 求导法则：线性 / 乘法 / 除法 / 链式（含证明） |
| 4 | 高阶导数与泰勒展开 |
| 5 | 数值微分：前向 / 中心差分与误差分析 |
| 6 | PyTorch autograd 交叉验证 |
| 7 | 导数与梯度下降：为什么负梯度是学习方向 |
| - | 课后练习 |

## 学习建议

- 每个公式先自己用极限定义推一遍，再看代码验证，不要先看答案
- 第 5 节的误差分析是本课最容易被忽视、也最有用的一节，务必看懂 log-log 图
- 课后练习独立完成，卡住再回看对应章节

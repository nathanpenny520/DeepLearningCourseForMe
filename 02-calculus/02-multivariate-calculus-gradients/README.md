# 02 · Multivariate Calculus & Gradients

多元微积分与梯度向量：偏导数、方向导数、梯度、等高线正交性、多元链式法则，用 PyTorch autograd 验证。核心结论：负梯度是函数下降最快的方向。

## 前置要求

- Python 3.12
- 已按 [`../guide.md`](../guide.md) 配置好虚拟环境并安装依赖
- 先完成 [01-derivatives](../01-derivatives)

## 课程内容

| 章节 | 内容 |
|------|------|
| 1 | 偏导数：固定其他变量的求导 |
| 2 | 方向导数与梯度：D_u f = ∇f·u |
| 3 | 梯度 = 最陡上升方向（证明 + 等高线正交） |
| 4 | 多元链式法则（路径上的全导数） |
| 5 | autograd 算多元梯度 |
| 6 | 梯度在深度学习中的意义 |
| - | 课后练习 |

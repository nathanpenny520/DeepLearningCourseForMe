# 02 · Matrix Operations

矩阵运算与线性变换：从向量点积到矩阵乘法，从转置到逆矩阵，最终用 2D 线性变换可视化建立几何直觉。代码为主，每个概念配多个可运行实例。

## 前置要求

- Python 3.12
- 已按 [`../guide.md`](../guide.md) 配置好虚拟环境并安装依赖
- 已完成 [01 Tensor Basics](../01-tensor-basics)（张量创建、形状操作、广播、按维统计）

## 课程内容

| 章节 | 内容 |
|------|------|
| 0 | 环境配置与导入 |
| 1 | 向量点积与范数（dot / inner / L1-L∞ 范数 / 余弦相似度） |
| 2 | 矩阵-向量乘法（行视角 / 列视角线性组合 / mv / @） |
| 3 | 矩阵-矩阵乘法（四种计算视角 / mm / matmul / 交换律与结合律） |
| 4 | 乘法函数全对比（dot vs mv vs mm vs bmm vs matmul 自动分发） |
| 5 | 转置与对称矩阵（t / transpose / permute / 连续性坑） |
| 6 | 迹 · 行列式 · 逆矩阵（trace / det / inv / linalg.solve） |
| 7 | 综合应用：2D 线性变换可视化（缩放 / 旋转 / 剪切 / 反射 / 复合变换） |
| - | 课后练习（基础 / 对比 / 几何 / 综合 / autograd 衔接） |

## 学习建议

- 每段代码都亲手运行，观察 shape 和数值变化
- 重点理解矩阵乘法的**列视角**（线性组合）和**外积视角**
- 第 7 节的可视化是整节课的几何收束，务必跑一遍
- 遇到环境问题先查 [`../guide.md`](../guide.md)

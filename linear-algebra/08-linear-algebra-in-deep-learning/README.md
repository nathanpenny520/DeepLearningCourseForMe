# 08 · Linear Algebra in Deep Learning

深度学习中的线性代数综合应用：全连接层、卷积的矩阵视角、注意力机制、归一化、优化中的线性代数、降维与表示学习、数值稳定性。代码为主，配可视化。

## 前置要求

- 已完成 01-07 节全部内容
- 关键前置：矩阵乘法、特征分解、SVD、投影与最小二乘、正定矩阵与条件数
